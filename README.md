## 🚀 Run Locally

Clone the repository:

```bash
git clone https://github.com/B277YASWANTH/My_Portfolio.git
```

Open the project folder:

```bash
cd My_Portfolio
```

Then open:

```text
index.html
```

in your browser.

No backend or installation is required.
